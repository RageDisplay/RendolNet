# Обновление

## Пакет

`rendolnet-<версия>.rnu` — обычный tar:

```
manifest.json            версия, дата сборки, версия k3s, список образов
images.tar.zst           docker save всех образов, сжатый zstd
manifests/rendolnet.yaml манифесты k3s под эту версию
host/usr/local/sbin/...  rendol-updater, rendol-console, rendol-installer, rendolctl
SHA256SUMS               суммы всех файлов выше
```

Собирается `make bundle` или `scripts/build-bundle.sh <версия>`, в CI — заданием
`package:bundle`.

Пакеты не подписываются. Проект открытый, собрать пакет может кто угодно, и
подпись одного ключа здесь ничего бы не доказала. `SHA256SUMS` ловит повреждение
при передаче. Доверять ли источнику пакета, решает администратор.

## Как ставится

```
веб: загрузить .rnu ──▶ rendol-api распаковывает в /var/lib/rendolnet/host/staging,
                          сверяя суммы на лету
веб: «Установить»    ──▶ rendol-api пишет request.json
                          systemd path-юнит запускает rendol-updater
rendol-updater:
  1. перепроверка сумм в staging
  2. k3s ctr images import (поток распаковывается из zstd на лету)
  3. резервная копия манифеста и заменяемых файлов узла
  4. файлы из host/ — через запись во временный файл и rename
  5. новый манифест в /var/lib/rancher/k3s/server/manifests
  6. ожидание: https://127.0.0.1/healthz должен ответить новой версией (5 минут)
  7. при неудаче — вернуть манифест и файлы узла, статус rolled_back
```

Ход установки и журнал шагов видны на странице «Обновление». Состояние лежит в
`/var/lib/rendolnet/host/status.json`.

Что не прерывается:

- фильтрация: программы eBPF закреплены и продолжают работать, пока под
  агента перезапускается;
- конфигурация и журнал: база и `/var/lib/rendolnet` не трогаются.

Веб-интерфейс недоступен около минуты, пока перезапускается API.

## Ограничения

- Понижение версии запрещено. Версии сравниваются как в `sort -V`.
- В `manifest.json` может быть `min_version`: пакет ставится только поверх
  неё или более новой.
- Ядро и пакеты Debian обновляются отдельно, через unattended-upgrades (только
  security). Узел сам не перезагружается; необходимость перезагрузки видна по
  `/run/reboot-required`.
- A/B-разделов пока нет: обновление ОС целиком пакетом не делается.
